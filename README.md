# ETF 괴리율·NAV 해석 도우미

국내 ETF를 직접 거래하지만 NAV와 괴리율 해석이 어려운 초보 개인투자자를 위한 Streamlit 프로토타입입니다. 금융위원회 공식 일별 데이터로 종가와 NAV의 차이를 계산하고, 한국거래소 ETF FAQ에 근거해 관련 개념을 설명합니다.

## 핵심 사용자와 과업

관심 ETF는 정했지만 종가와 NAV의 차이를 해석하기 어려운 개인투자자가 핵심 사용자입니다. 서비스는 다음 세 가지 질문에 집중합니다.

1. 이 ETF의 종가와 NAV는 얼마나 차이 나는가?
2. 공식 일별 데이터 기준으로 할증 또는 할인 상태인가?
3. 괴리율, LP, 추적오차는 무엇이며 왜 발생하는가?

## 데이터 소스와 지원 범위

- 운영자가 `data` 폴더에 등록한 한국거래소 ETF FAQ PDF: NAV, 괴리율, LP, 추적오차 등 관련 개념
- 금융위원회 증권상품시세정보 OpenAPI: 괴리율 계산에 사용하는 종가와 NAV 및 기준일
- Google Gemini API: 문서 임베딩과 FAQ 문맥 기반 답변. 채팅 모델은 Google 공식 모델 ID인 [`gemini-3.5-flash`](https://ai.google.dev/gemini-api/docs/models)를 사용합니다.

종목 추천, 미래 가격 예측, 실시간 시세, 뉴스, 세금, 수수료, 배당, 포트폴리오 질문은 지원하지 않습니다. 검색어가 모호하면 최대 10개의 ETF 후보를 제시하고 사용자가 직접 선택하게 합니다.

## 계산과 AI의 역할

괴리율은 LLM이 아니라 애플리케이션 코드가 다음 공식으로 계산합니다.

```text
괴리율 = (종가 - NAV) / NAV × 100
```

- 공식 API: 종가, NAV, ETF 식별 정보와 기준일 제공
- 계산 로직: 가격 차이, 괴리율, 할증·할인 상태 산출
- RAG와 Gemini: 등록된 FAQ 문서에 근거한 짧고 자연스러운 해석과 개념 설명

종가 또는 NAV가 없거나 NAV가 0 이하이면 괴리율을 계산하지 않습니다. 할증·할인은 데이터 상태를 중립적으로 설명하며 매수·매도 신호로 해석하지 않습니다.

## 대화 방식

분석 수치와 계산식은 코드가 고정하고, 그 아래의 해석만 Gemini가 FAQ 근거로 작성합니다. Gemini 또는 FAQ 검색을 사용할 수 없더라도 공식 데이터 분석은 유지되고 기본 해석으로 대체됩니다.

직전 분석의 ETF 이름·코드·기준일·괴리율·가격 차이·할증 또는 할인 상태는 현재 세션에만 보관합니다. 따라서 분석 후 `왜 그런 거야?`, `무슨 뜻이야?`, `언제 기준이야?`, `이 정도면 안정적인 거야?`처럼 이어서 질문할 수 있습니다. 한 기준일의 괴리율이 0에 가깝다는 사실만으로 안정성을 단정하지 않고 기간별 괴리율, 유동성, 호가 스프레드와 추적오차를 함께 확인하도록 안내합니다. `대화 초기화`를 누르면 이 문맥도 함께 삭제됩니다.

ETF가 명시된 단순 수치 질문은 공식 API 분석으로 처리합니다. `왜`, `차이`, `설명`처럼 개념 설명을 요구하는 표현이 함께 있을 때만 API와 FAQ를 결합합니다. 반대로 `가장 최신 일별 데이터 괴리율 보여줘`처럼 ETF가 빠진 수치 질문에는 문서 답변을 억지로 생성하지 않고 ETF 이름이나 종목코드를 다시 요청합니다.

답변 말투는 차분한 금융 데이터 분석가를 기준으로 하며 인사, 형식적인 칭찬, 감탄사, 이모지와 과장된 친근함을 사용하지 않습니다.

## 파일

- `app.py`: Streamlit UI, 세션 및 후보 선택 관리
- `rag_module.py`: 공식 데이터 조회, 괴리율 계산, 범위 라우팅, PDF RAG
- `test_gemini.py`: 배포 전 운영자가 수동 실행하는 Gemini API 키·채팅 모델 연결 점검
- `test_rag_module.py`: 외부 API 호출 없이 핵심 라우팅·검색·캐시 동작을 검증하는 회귀 테스트
- `.env.example`: 환경변수 예시

FAQ PDF는 기본적으로 `data/ETF_FAQ.pdf`에 등록합니다. 다른 위치나 이름을 사용하면 `FAQ_PDF_PATH` 환경변수로 지정할 수 있습니다. 앱 시작 시 PDF 해시와 일치하는 FAISS 인덱스를 불러오며, 없으면 자동 생성합니다. `vectorstore`에는 현재 문서와 직전 문서의 인덱스만 남기고 더 오래된 해시 인덱스는 자동 정리합니다.

RAG 검색은 상위 4개 결과 중 관련성 점수가 `0.5` 이상인 청크만 답변 근거로 사용합니다. 기준을 통과한 청크가 없으면 Gemini를 호출하지 않고 문서에서 내용을 확인할 수 없다고 안내합니다.

`괴리율과 추적오차의 차이`처럼 비교 대상이 서로 다른 페이지에 있는 질문은 각 개념을 추가로 검색해 근거 청크를 합칩니다. 근거가 부족해 거절하는 답변에는 오해를 줄 수 있는 출처 목록을 표시하지 않습니다.

## 요구 환경과 라이브러리

- Python 3.10 이상
- `streamlit`: 웹 채팅 UI
- `python-dotenv`: `.env` 환경변수 로드
- `requests`: 금융위원회 OpenAPI 호출
- `pymupdf`: FAQ PDF 텍스트 추출
- `faiss-cpu`: FAQ 벡터 검색 인덱스
- `langchain-core`, `langchain-community`, `langchain-text-splitters`: 문서·Retriever·텍스트 분할
- `langchain-google-genai`: Gemini 채팅 및 임베딩 연동

정확한 설치 목록은 `requirements.txt`에서 관리합니다. 개별 설치보다 다음의 일괄 설치 명령을 사용하세요.

## API 키 발급

### Gemini API 키

1. [Google AI Studio API Keys](https://aistudio.google.com/app/apikey)에 로그인합니다.
2. 프로젝트를 선택하거나 생성한 뒤 Gemini API 키를 발급합니다.
3. 발급한 값을 `.env`의 `GEMINI_API_KEY`에 입력합니다.

Gemini 키는 FAQ 문서 임베딩과 문서 기반 답변 생성에 사용됩니다. 계정과 지역, 요금제에 따라 사용량 제한이 적용될 수 있습니다.

### 금융위원회 공공데이터 API 키

1. 공공데이터포털의 [금융위원회 증권상품시세정보 OpenAPI](https://www.data.go.kr/data/15094806/openapi.do)에 로그인합니다.
2. **활용신청**을 완료하고 마이페이지에서 서비스 키를 확인합니다.
3. 인코딩 키 또는 디코딩 키 중 하나를 `.env`의 `DATA_GO_KR_API_KEY`에 입력합니다. 이 프로젝트는 두 형식을 모두 처리합니다.

활용신청 승인 상태, 일일 호출 한도 및 서비스 키 활성화 여부에 따라 호출이 실패할 수 있습니다.

## 설치와 환경변수 설정 (Windows PowerShell)

프로젝트 루트에서 다음 명령을 순서대로 실행합니다.

```powershell
python -m venv etf
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
.\etf\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

생성된 `.env`를 열어 다음 형식으로 설정합니다.

```dotenv
GEMINI_API_KEY=발급받은_Gemini_API_키
DATA_GO_KR_API_KEY=발급받은_공공데이터_서비스_키
FAQ_PDF_PATH=data/ETF_FAQ.pdf
```

`FAQ_PDF_PATH`는 프로젝트 루트 기준 상대경로나 절대경로를 사용할 수 있습니다. 기본 파일이 `data/ETF_FAQ.pdf`에 있다면 예시 값을 그대로 사용합니다.

API 키 양옆에 불필요한 공백을 넣지 마세요. `.env`를 Git에 커밋하거나 API 키를 코드, 로그, 화면에 출력해서는 안 됩니다.

## 테스트와 연결 확인

코드 회귀 테스트는 네트워크나 API 키 없이 실행할 수 있습니다.

```powershell
python -m unittest discover -v
```

배포 전에 실제 Gemini 연결을 확인하려면 다음 명령을 운영자가 수동 실행합니다. 이 스크립트는 자동화 테스트가 아니며 실제 API 요청 1회를 사용합니다. 성공하면 짧은 Gemini 응답이 출력되지만 API 키 자체는 출력되지 않습니다.

```powershell
python test_gemini.py
```

공공데이터 API는 앱에서 `069500` 또는 `KODEX 200 괴리율 분석`과 같은 입력으로 확인할 수 있습니다.

서비스 키가 유효하더라도 공공데이터의 최신 기준일이 최근 거래일보다 늦게 반영될 수 있습니다. 앱은 API가 실제로 반환한 기준일을 그대로 표시하며, 오늘과 3일보다 많이 차이 나면 데이터 반영 지연 가능성을 경고합니다. 이 기준은 휴장일을 계산한 거래일 판정이 아니라 사용자가 오래된 데이터를 놓치지 않도록 하는 보수적인 달력 일수 경고입니다.

## 앱 실행

```powershell
streamlit run app.py
```

터미널에 표시되는 로컬 주소(일반적으로 `http://localhost:8501`)를 브라우저에서 엽니다. 운영자가 FAQ PDF를 등록한 상태에서 앱을 실행하면 지식베이스가 자동 준비되며, 고객은 파일 업로드 없이 바로 질문합니다.

종료할 때는 실행 중인 터미널에서 `Ctrl+C`를 누릅니다. 패키지나 코드를 변경한 뒤 동작이 반영되지 않으면 앱을 종료하고 같은 명령으로 다시 실행하세요.

## 한계와 보안

데이터는 실시간이나 항상 전일 데이터라고 보장되는 값이 아니라, 공공데이터 API가 현재 제공하는 최신 일 단위 기준값입니다. 따라서 장중 매매 판단이나 실시간 괴리율 감지에 사용할 수 없습니다. FAQ 답변 품질은 PDF의 텍스트 추출 가능 여부에 좌우됩니다. 기간별 괴리율 추이, ETF 간 비교, 종목 추천은 현재 범위 밖입니다. `.env`는 Git에서 제외되며 본 서비스는 투자 추천이나 수익 보장 서비스가 아닙니다.

## 품질 기준

- API 원본의 종가·NAV·기준일을 변경하지 않고 표시
- 숫자 계산은 LLM을 사용하지 않으며 테스트에서 고정
- LLM 해석 실패가 공식 데이터 분석 실패로 이어지지 않음
- 직전 ETF 분석에 대한 짧은 후속 질문 문맥 유지
- 근거 점수 기준을 통과한 FAQ 청크만 설명에 사용
- 미지원 질문은 분석할 ETF 이름 또는 코드 입력으로 유도
- 모든 수치 답변에 공식 출처와 일 단위 데이터 안내 표시
